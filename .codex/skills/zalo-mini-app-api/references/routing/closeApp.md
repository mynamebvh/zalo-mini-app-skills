# closeApp

> Source: https://docs.zaloplatforms.com/docs/MA/api/routing/closeApp
> Last updated: 28/10/2026

```ts
import { closeApp } from "zmp-sdk";
```

API that requests to close the Zalo Mini App.

## Example

Close the Zalo Mini App:

```ts
closeApp();
```
