# 5. Mini App Performance

> Source: https://miniapp.zaloplatforms.com/documents/zalo-mini-app-censorship-policy/#5-hiệu-suất-mini-app
> Accessed: 2026-11-02

- Features work normally
- Incidents during use
- App load time

## 5.1 Features work normally

**Violation**

![Violation](https://miniapp.zaloplatforms.com/documents/img/censorship-policy/v2/5.1.a.png)

- Some or all features are unusable
- Some or all features are in Demo state

**Compliant**

![Compliant](https://miniapp.zaloplatforms.com/documents/img/censorship-policy/v2/5.1.b.png)

- All features work normally
- If the developer needs the Mini App reviewed for certain reasons, please contact hotrodoitac@zaloplatforms.com for support

## 5.2 Incidents during use

**Violation**

- The Mini App freezes, white/black screen

**Compliant**

- No errors occur during use of the Mini App

## 5.3 App load time

**Violation**

- Mini App/Mini App feature load time > 10 seconds

**Compliant**

- Largest Contentful Paint (LCP) load time under 2.5 seconds
- Page load time (PageLoad Time) under 1.5 seconds
- Standard-compliant Mini App load time, refer to [here](https://mini.zalo.me/blog/huong-dan-cai-thien-hieu-suat-lcp-cho-zalo-mini-app-2/)
