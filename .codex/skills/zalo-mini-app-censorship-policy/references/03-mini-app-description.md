# 3. Mini App Description

> Source: https://miniapp.zaloplatforms.com/documents/zalo-mini-app-censorship-policy/#3-mô-tả-mini-app
> Accessed: 2026-11-02

- Description appropriate to the Mini App's feature/functionality
- The description must not contain links, any content that violates good customs and traditions, or content prohibited by law

## 3.1 Description appropriate to the Mini App's feature/functionality

**Violation**

![Violation](https://miniapp.zaloplatforms.com/documents/img/censorship-policy/v2/3.1.a.png)

- The description does not reflect or is unrelated to the Mini App's functionality & purpose
- The Mini App has no description

**Compliant**

![Compliant](https://miniapp.zaloplatforms.com/documents/img/censorship-policy/v2/3.1.b.png)

- The description accurately states the Mini App's functionality, audience, and purpose
