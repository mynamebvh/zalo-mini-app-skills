# 8. Checkout SDK Integration

> Source: https://miniapp.zaloplatforms.com/documents/zalo-mini-app-censorship-policy/#8-tích-hợp-checkout-sdk
> Accessed: 2026-11-02

A Mini App with payment functionality is required to integrate the Checkout SDK. For details on the integration documentation, see [here.](https://mini.zalo.me/documents/checkout-sdk)

**Checkout SDK required**

- The Mini App generates orders, has payment functionality, and displays prices directly on the Mini App.

**Checkout SDK not required**

- If the Mini App currently has no need to use the Checkout SDK, please do not display product/service prices and change the purchase – payment function to "Contact" or "Consultation".
