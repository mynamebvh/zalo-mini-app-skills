## ZaUI Components

ZaUI Components includes the ZaUI mini app, design library file sets, and accompanying guidelines designed to help you shorten Mini App development time and create a user-friendly interface.

The library provides the basic design components needed for a Mini App. The components and design documentation of ZaUI Components are customized and condensed from the ZDS library — Zalo's official design system.

tip

ZaUI Components provides most of the basic components needed for a Mini App and will be continuously updated according to the Design System of the Zalo Mini App Team. You can refer to the design documentation [here](https://www.figma.com/file/ME5AP7pt79huTBTMdnT7yX/%5BPUBLIC%5D-Zalo-Mini-App-Framework-2.0?node-id=0%3A1).
