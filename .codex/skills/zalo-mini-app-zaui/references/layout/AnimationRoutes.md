# AnimationRoutes

> Source: https://docs.zaloplatforms.com/docs/MA/zaui/layout/AnimationRoutes

Last updated: October 28, 2026

```ts
import { AnimationRoutes } from "zmp-ui";
```

Used to declare a route to a page in the app while adding a page transition effect.


## Props

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| children | React.ReactNode | No | The `<Route>` elements organized within this route group. |
