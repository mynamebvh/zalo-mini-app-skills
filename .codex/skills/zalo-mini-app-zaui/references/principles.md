# Principles

> Source: https://docs.zaloplatforms.com/docs/MA/zaui/principles

Last updated: October 28, 2026

## 1. Let users control the interface

Good UI gives users a sense of control, making it easy for them to understand and master the product.

- Allow actions to be undone
- Keep the interface easy to navigate
- Provide feedback for actions
- Show system status

## 2. Make interactions with the product comfortable

- Remove all elements that are not useful to users
- Do not make users re-enter information they have already entered
- Avoid confusing terminology
- Apply Fitts's law to interactive elements
- Use real-world metaphors
- Communicate errors effectively
- Ensure users do not lose their work

## 3. Reduce unnecessary thinking

- Break information into a sequence
- Reduce the number of required actions to achieve a goal

## 4. Consistency

- Consistent interface
- Consistent functionality
- Match user expectations
