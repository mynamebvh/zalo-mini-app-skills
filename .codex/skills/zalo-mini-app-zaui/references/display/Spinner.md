# Spinner

> Source: https://docs.zaloplatforms.com/docs/MA/zaui/display/Spinner

Last updated: 28/10/2026

```ts
import { Spinner } from "zmp-ui";
```

Used to show a loading state for content that is not yet ready to be displayed.


## Props

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| visible | boolean | No | The display state of the spinner. (default: `true`) |
| logo | React.ReactNode | No | The element used as the logo, displayed in the center of the spinner. |
