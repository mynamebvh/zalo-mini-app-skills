# Switch

> Source: https://docs.zaloplatforms.com/docs/MA/zaui/form/Switch

Last updated: 28/10/2026

```ts
import { Switch } from "zmp-ui";
```

Used to create a toggle that allows users to turn a function on or off


## Props

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| label | string | No | The label of the switch, displayed next to the switch. |
| size | 'medium' \| 'small' | No | The size of the switch. (default: `'medium'`) |
| wrapperClassName | string | No | The CSS class of the element containing the switch and label, if any. |
